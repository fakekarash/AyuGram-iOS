# Calculator icon source

`Assets/Calculator.png` is generated by `build-system/make_calculator_icon.py`
(1024x1024, opaque, full-bleed). It is a plain calculator drawing — a light body
on a near-black background with a dark display strip and a keypad whose last
column is orange — so that the app reads as a calculator on the Home Screen.

Re-generate with:

```bash
python3 build-system/make_calculator_icon.py
```

Edit the colours and geometry in that script; do not hand-edit the PNG.
