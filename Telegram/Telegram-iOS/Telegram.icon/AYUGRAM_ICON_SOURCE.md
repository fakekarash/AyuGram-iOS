# AyuGram icon source

`Assets/AyuGram.png` is derived from the official AyuGram Desktop application icon:

https://github.com/AyuGram/AyuGramDesktop/blob/dev/Telegram/Resources/art/icon512@2x.png

The transparent source was composited over an opaque `#2A2344` background because iOS application icons must be opaque. The artwork itself was not redrawn.
