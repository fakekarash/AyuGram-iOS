# AyuGram iOS: паритет функций

Документ фиксирует, что именно есть в оригинальном AyuGram, что из этого сделано
в этом форке и что делать дальше. Источники: исходники `AyuGram/AyuGram4A`
(ветка `rewrite`, GPL‑2.0), `AyuGram/AyuGramDesktop` (GPL‑3.0) и
`docs.ayugram.one`.

## 1. Структура настроек оригинала

AyuGram Android (`AyuGramPreferencesActivity`, вход: свой профиль → «Настройки
AyuGram») строит шесть заголовков:

| Заголовок | Содержимое |
| --- | --- |
| Режим призрака | мастер‑переключатель + 4 чекбокса + 2 тумблера |
| Режим шпиона | сохранение удалённых, история правок, настройки сохранения сообщений |
| Полезные функции | AyuGram Push Service, отключение рекламы, локальный Premium, фильтры сообщений |
| Персонализация | метка удалённого, метка изменённого, переключатель в drawer, кнопка закрытия |
| AyuSync | синхронизация прочитанного/истории между устройствами |
| Debug | WAL, очистка Ayu‑БД, стирание локальной БД |

Заголовки «Категории» и «Ссылки» (Канал `@ayugram1338`, Чаты `@ayugramchat`,
Перевод → Crowdin, Исходный код → GitHub) находятся на главном экране настроек
exteraGram, а не в AyuGram‑экране. Именно этот экран и был взят за образец
оформления: шапка с иконкой, «КАТЕГОРИИ», «ССЫЛКИ».

## 2. Режим призрака (точный список)

| RU | EN | Поведение | Статус здесь |
| --- | --- | --- | --- |
| Не отправлять «прочитано» | Don't read messages | подавляет `messages.readHistory`, `readChannelHistory`, `readMessageContents`, `readDiscussion` | сделано (`hideReadReceipts`) |
| Не отправлять «онлайн» | Don't send online | каждый `account.updateStatus` переписывается в `offline = true` | сделано (`stayOffline`) |
| Не отправлять «печатает» | Don't send typing | выкидывает `messages.setTyping` | сделано (`hideTyping`) |
| Читать после ответа | Send read status after reply | отложенный read receipt | не сделано |
| Автоматический «офлайн» | Immediate offline after online | офлайн сразу после онлайна | покрыто `stayOffline` |
| Использовать отложку | Schedule messages | отправка через `schedule_date = now + 10s` | не сделано |

В iOS подавление сделано на уровне TelegramCore (`ApplyMaxReadIndexInteractively`,
`ManagedSynchronizeConsumeMessageContentsOperations`,
`ManagedSynchronizeViewStoriesOperations`, `ManagedAccountPresence`,
`ManagedLocalInputActivities`) — это тот же принцип, что единая точка
`ConnectionsManager.sendRequestInternal` в Android.

## 3. Режим шпиона

| RU | Поведение | Статус здесь |
| --- | --- | --- |
| Сохранять удалённые сообщения | сообщение остаётся в чате с меткой удалённого | сделано |
| Сохранять историю правок | все ревизии + пункт «История» в контекстном меню | сделано |
| Настройки сохранения сообщений | по типам чатов, типам контента, форматирование, реакции, боты | частично: категории (личные/группы/каналы/боты), типы контента, точечные правила «всегда/никогда», ретенция и лимит |

Чего не хватает из «Настроек сохранения»: разделение публичных и приватных
каналов/групп (в оригинале публичные каналы и группы по умолчанию **выключены**),
сохранение форматирования, реакций, диалогов с ботами как отдельных тумблеров.

## 4. Полезные функции

| Функция | Что делает | Переносимость |
| --- | --- | --- |
| Фильтры сообщений | пользовательские regex; скрывают сообщение в чате, размывают в списке чатов, исключают из автозагрузки | переносимо в три точки TelegramUI |
| Отключение рекламы | не показывать sponsored messages | переносимо (`AdUI`) |
| Локальный Premium | клиентский флаг premium | рискованно: сервер может отвергнуть функции |
| AyuGram Push Service | foreground‑сервис для сокета | Android‑only, вместо этого у нас локальные уведомления и keep‑alive |
| AyuSync | WebSocket‑синхронизация состояния | переносимо, но требует сервера |

## 5. Персонализация

| Функция | Статус здесь |
| --- | --- |
| Метка удалённого (текст) | сделано: пресеты `🛡 AyuGram` / `🧹` / `🪦` / `✖️` / без метки |
| Метка изменённого | не сделано |
| Переключатель в drawer | неприменимо (нет drawer в iOS) |
| Кнопка закрытия приложения | неприменимо (iOS не даёт закрыть процесс) |

## 6. Что сделано в этом форке (по состояниям)

| Слой | Состояние |
| --- | --- |
| Оформление экрана AyuGram | шапка (иконка/имя/версия), КАТЕГОРИИ с тремя подэкранами, ССЫЛКИ (Канал, Чаты, Перевод, GitHub), RU+EN |
| Режим призрака | 5 из 6 пунктов (нет только «отложки» через `schedule_date`) |
| Шпион | удалённые, правки, метка удалённого (5 пресетов), уведомления, хранилище, очистка хранилища и архива, фильтры сохранения |
| Фильтры | категории, публичные/приватные каналы и группы, типы контента, точечные правила, ретенция, лимит, реклама off, метка изменённого |
| Уведомления | локальные уведомления + опциональный keep‑alive + BGAppRefresh |
| Приватность | хранилище вне бэкапа и вне Files, view-once/защищённый контент по умолчанию выключены, повторный Face ID при уходе в фон |
| Производительность | обслуживание хранилищ с троттлингом вместо O(N) на запись |

## 7. Порядок дальнейшей работы

1. Довести «Режим призрака» до полного набора: «читать после ответа», отложенная
   отправка.
2. Regex‑фильтры сообщений: настройки + три точки интеграции.
3. Настройки сохранения: публичные/приватные каналы и группы, форматирование,
   реакции, боты.
4. Метка изменённого, отключение рекламы.
5. AyuSync — последним, так как требует серверной части.

Не переносим: foreground push service, drawer‑переключатели, кнопка закрытия,
апдейтер, «tabs».
