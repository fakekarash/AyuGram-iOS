# AyuGram iOS 1.2.0

Сборка поверх Telegram-iOS 13.0. Ветка `ayugram-stage5`.

## Маскировка под калькулятор

- Иконка повторяет системный калькулятор: светлая плитка, тёмный корпус, бледный
  дисплей и оранжевая колонка клавиш; название — «Калькулятор»
  (`CFBundleDisplayName` берётся из UTF-8-литерала в `ayugram_sideload_ci.py`;
  вход сборки `display_name` принимает только ASCII-переопределение, потому что
  CI портит не-ASCII значения на «???»).
- **Свой bundle id** (`com.fakekarash.calculator` через `bundle_id`, схема
  `calculator` через `url_scheme`), поэтому маскировка ставится **рядом** с
  обычным AyuGram и не конфликтует с ним ни идентификатором, ни URL-схемой.
- Интерфейс как у системного калькулятора iOS 26: чёрный фон, круглая кнопка
  истории слева и переключатель «обычный/научный» справа, крупный дисплей,
  клавиши-«пилюли». В научном режиме — `( )`, память `mc m+ m− mr`, `2nd`,
  `x² x³ xʸ eˣ 10ˣ`, `1/x ²√x ³√x √x ln log₁₀`, `x! sin cos tg e EE`,
  `Rand sh ch th π Rad/Deg`.
- Всё это считается по-настоящему: выражения с приоритетами и скобками,
  автоматическое закрытие скобок, факториал, логарифмы, корни, тригонометрия
  в градусах и радианах, гиперболические функции, `EE`, память, история
  последних 30 вычислений (кнопка часов) и `⌫`.
- Telegram открывается вводом кода **`2024`** и нажатием **`=`**. Любой другой
  ввод просто считает — в том числе `2+2=`, `sin(30)=`, `(2+3)×4=`.
- По умолчанию (переключатель «Запирать при уходе в фон») приложение снова
  показывает калькулятор уже при уходе в фон, поэтому снапшот в переключателе
  приложений тоже показывает калькулятор, а не чаты.
- Пока калькулятор на экране, локальные уведомления с названиями чатов и текстом
  сообщений не показываются.
- Пока калькулятор на экране, запрос Face ID не выполняется.
- Всё переключается в **AyuGram → Шпион → МАСКИРОВКА**; отключение режима вступает
  в силу сразу. Код разблокировки намеренно не редактируется из UI, чтобы нельзя
  было запереть себя снаружи; восстановление при утере — переустановка.
- Иконки из «галереи альтернативных иконок» Telegram убраны, чтобы через долгое
  нажатие на иконку приложение не выдавало себя.

## Оформление

- экран **AyuGram** переделан по образцу: шапка с иконкой, именем и версией,
  раздел **КАТЕГОРИИ** (Режим Призрака, Шпион, Фильтры) и раздел **ССЫЛКИ**
  (Канал, Чаты, Перевод, GitHub проекта);
- строки на русском и английском, без облачных языковых пакетов.

## Приватность по умолчанию

- «Сохранять одноразовые медиа» и «Сохранять защищённый контент» **выключены**
  до явного включения;
- хранилище и архив удалённых сообщений **зашифрованы AES-GCM**, ключ 256 бит
  лежит только в Keychain этого устройства (`afterFirstUnlockThisDeviceOnly`),
  не синхронизируется и не попадает в резервные копии;
- данные исключены из бэкапа и больше не видны в приложении «Файлы»;
- при включённой защите Face ID хранилище закрывается, как только приложение
  уходит в фон, и снова спрашивает биометрию при открытии.

## Режим Призрака (5 из 6 пунктов)

- не отправлять прочтение;
- читать после ответа (квитанция уходит только когда вы ответили);
- скрывать просмотры историй;
- скрывать «печатает»;
- всегда офлайн.

## Шпион

- сохранение удалённых сообщений с меткой (5 пресетов), полупрозрачный пузырь;
- история редактирования по долгому нажатию;
- дебат-уведомления: bulletin в приложении и опциональные системные уведомления;
- хранилище: поиск, фильтры, превью, отправка, очистка чата, очистка всего;
- локальные уведомления о новых сообщениях, опциональный режим «не выгружать из
  памяти», резервное фоновое обновление, кнопка проверки уведомления.

## Фильтры

- категории чатов, публичные каналы и группы **по умолчанию не сохраняются**;
- типы контента (текст, фото, видео, голосовые, файлы, стикеры, одноразовые);
- индивидуальные правила «всегда / никогда / общие»;
- срок хранения, лимит размера хранилища;
- реклама в чатах **отключена**;
- опциональная метка изменённого сообщения.

## Технические изменения

- подпись фейковых provisioning-профилей переведена на самоподписанный
  сертификат репозитория (срок до 2036), добавлен `renew_fake_profiles.py`;
- воркфлоу: все GitHub Actions запинены по SHA, сборка поддерживает
  `--keep_going`, внешние репозитории Bazel кешируются между прогонами;
- сборка возможна локально одной командой — `build-system/build_sideload_on_mac.sh`;
- добавлены первые unit-тесты на логику настроек AyuGram;
- обслуживание хранилищ с троттлингом, снапшот Vault читается в фоне;
- исправлено: удаления по global id теперь доходят до UI-состояния.

## Ограничения

- **push-уведомлений от Telegram нет**: сборка переподписывается, у неё нет
  APNs-топика. Вместо них приложение показывает локальные уведомления.
  Пошаговый путь к настоящим push — в `AYUGRAM_NOTIFICATIONS.md`;
- расширения приложения отсутствуют (share, виджеты, Notification Service);
- IPA нужно переподписать своим Apple ID перед установкой;
- `api_id`/`api_hash` вшиты в бинарник: не распространять публично.
