# AyuGram iOS: сборка, установка и проверка на устройстве

## 1. Как получается IPA

```text
Telegram-iOS (ветка ayugram-stage5)
   → CI: makos-26 + Xcode 26.6 + Bazel 9.2.0
   → upstream fake signing → Telegram.ipa
   → repackage: убрать расширения, переписать bundle id на com.fakekarash.ayugram,
     убрать _CodeSignature и embedded.mobileprovision
   → AyuGram.ipa (переподписываемая, без расширений)
```

Два пути:

- **CI**: воркфлоу `AyuGram iOS build from fork` в репозитории
  `fakekarash/ayugram-ci-runner` (он чекаутит форк по конкретному SHA и собирает).
  Секреты `TELEGRAM_API_ID`/`TELEGRAM_API_HASH` должны лежать в этом репозитории.
  Если они не заданы — сборка идёт с заглушкой (`dummy_credentials=true`) и
  годится только как проверка компиляции: войти в аккаунт в ней нельзя.
- **Локально на Mac**: `build-system/build_sideload_on_mac.sh` (см. ниже).

Артефакты: `AyuGram.ipa` + `manifest.json` (SHA-256, версии, список фич,
`device_installation_tested: false`).

## 2. Установка на iPhone

В IPA **нет** Apple-сертификата и provisioning profile — её нужно подписать своим.

| Инструмент | Что нужно | Ограничения |
| --- | --- | --- |
| AltStore / SideStore | Apple ID, AltServer/pairing | бесплатный аккаунт: переподпись каждые 7 дней, до 3 приложений |
| Sideloadly | компьютер + Apple ID | для push-энтайтлментов нужен платный аккаунт |
| Xcode | Mac + Apple ID | самый предсказуемый путь |

Что перестаёт работать из-за отсутствия расширений: push-уведомления от
Telegram, share-extension, виджеты, Notification Service (богатые уведомления).
Вместо push приложение показывает локальные уведомления (см.
[AYUGRAM_NOTIFICATIONS.md](AYUGRAM_NOTIFICATIONS.md)).

## 3. Локальная сборка на Mac

```bash
export TELEGRAM_API_ID=…
export TELEGRAM_API_HASH=…
./build-system/build_sideload_on_mac.sh          # ~40–60 минут на холодном кэше
```

Если Xcode/macOS отличаются от `versions.json` — добавь
`AYUGRAM_ALLOW_UNPINNED=1`: пины версий станут предупреждениями, SHA-256 Bazel
всё равно проверяется.

Если сборка падает на профилях — `python3 build-system/renew_fake_profiles.py`
переподпишет их, `--check` покажет состояние.

## 4. Что проверить на устройстве

Порядок отражает то, что уже реализовано.

### Оформление

1. Иконка на домашнем экране — калькулятор, подпись — «Калькулятор» (или то имя,
   что передано в `display_name` при сборке).
2. Запуск открывает калькулятор; `2024` + `=` открывает Telegram; другая арифметика
   считается как в обычном калькуляторе.
3. Уйти в фон и вернуться: калькулятор снова на экране (если включён
   «Запирать при уходе в фон»); в переключателе приложений виден калькулятор.
4. Настройки → **AyuGram**: сверху иконка, имя и версия, затем **КАТЕГОРИИ**
   (Режим Призрака, Шпион, Фильтры) и **ССЫЛКИ**. Строки должны быть на языке
   системы (RU/EN), без обрезаний при крупном размере текста.

### Режим Призрака

2. Включить режим, открыть непрочитанное сообщение с другого аккаунта —
   отправитель не должен увидеть «прочитано».
3. Проверить набор текста (индикатор не появляется), просмотр истории,
   онлайн-статус.
4. Выключить режим — обычное поведение должно вернуться.

### Шпион

5. Удалить сообщение с другого аккаунта: оно остаётся в чате, подсвечено
   полупрозрачно и помечено меткой (по умолчанию `🛡 AyuGram`), метка
   переключается в Шпион → «Метка удалённого».
6. Отредактировать сообщение дважды: долгое нажатие → «AyuGram: история
   изменений».
7. Удалить сообщение с фото, которое уже скачано: файл должен появиться в
   хранилище (Шпион → «Открыть хранилище»).
8. Открыть одноразовое фото — при включённом «Сохранять одноразовые медиа» оно
   попадает в хранилище; при выключенном — нет.
9. В хранилище: поиск, фильтры, превью, «Поделиться», «Очистить этот чат»,
   «Очистить хранилище».
10. Включить «Защищать хранилище Face ID», свернуть приложение с открытым
    хранилищем — при возврате оно должно закрыться и снова спросить Face ID.

### Фильтры

11. Выключить «Каналы» и «Группы» — новые удалённые сообщения из них не
    сохраняются.
12. «…в открытых каналах/группах» по умолчанию выключены: публичные каналы не
    сохраняются, пока их не включить.
13. Индивидуальные правила: «Всегда сохранять» перебивает категории.
14. «Показывать рекламу в чатах» выключено → спонсорские блоки не появляются.

### Уведомления

15. Шпион → «Системные уведомления»: выдать разрешение, нажать «Проверить
    уведомление» — должно прийти сразу.
16. Приложение в фоне, приходит сообщение → локальное уведомление (при
    включённом «Не выгружать из памяти» — сразу, иначе как получится).
17. Удалить сообщение с другого аккаунта, пока приложение открыто → в приложении
    появляется bulletin «AyuGram».

### Хранилище и приватность

18. В приложении «Файлы» папки AyuGram **не должно быть** — доступ к хранилищу
    только внутри приложения.
19. Метаданные архива в `Documents/AyuGram Archive` должны быть бинарными
    (AES-GCM), а не читаемым JSON (проверяется только при доступе к контейнеру).

## 5. Известные ограничения

- Нет APNs: push невозможен без платного Apple Developer + своего APNs-сертификата
  на `my.telegram.org/apps/apns_cert` (пошагово в [AYUGRAM_NOTIFICATIONS.md](AYUGRAM_NOTIFICATIONS.md)).
- Нет расширений приложения: без share-виджета, виджетов, богатых уведомлений.
- `api_id`/`api_hash` вшиты в бинарник: не раздавай сборку публично с «личной»
  парой — для публичных релизов делай отдельное API-приложение.
- Debug-сборки Telegram-iOS собираются с `-Onone`, релизные — с оптимизацией;
  поведение по скорости может отличаться.
